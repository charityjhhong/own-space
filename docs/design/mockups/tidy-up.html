Tidy up tab, every step

The four views of Tidy up: draw a box, pick a look (thumbnail cards from #264), done, and an existing cover selected.

What changes
  1. Picture cards replace the colour dots, with the same thumbnails as the furniture cards.
  2. The stepper has no number discs or outlines; only text and a check.
  3. Every look is a big touch target (84 x 92 mm) and the chosen one is filled.

Wording changes (Remove cover) are on the rules page.
